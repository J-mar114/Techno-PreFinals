# BM2506 Interactive Quiz Portal & Reviewer

An interactive, responsive web-based quiz and reviewer portal designed for **BM2506 (STI Courseware Assessment)** covering items compiled directly from **07 Quiz 1** and **08 Quiz 1**.

## 🚀 Features

- **Modular & Clean Architecture**: Cleanly separated into standard HTML5, CSS3, and modern ES6 JavaScript (`index.html`, `style.css`, and `script.js`).
- **Multiple Assessment Modes**:
  - **07 Quiz 1**: Practice set 1 with authentic exam questions.
  - **08 Quiz 1**: Practice set 2 with complete problem coverage.
  - **Full Mock Exam**: Combined assessment simulating the comprehensive test.
- **Immediate Feedback & Explanations**: Instant grading with in-depth rationales, detailed answer keys, and references for each item.
- **Answer Key Review**: Filter results easily by *All Items*, *Correct Only*, or *Incorrect Only*.
- **Score Tracking & Local Storage**: Automatically saves and displays your best scores locally in your browser.
- **Responsive UI**: Optimized for desktop, tablet, and mobile devices with a clean and modern user interface.
